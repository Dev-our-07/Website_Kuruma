# Website_Kuruma

A small static website project for the Kuruma site. The repository contains simple HTML and CSS files that can be viewed locally in a browser.

Getting started

- Open `index.html` in your browser to view the site locally.
- The project contains additional pages: `home.html`, `contact.html`, and `info.html` with corresponding CSS files.

Repository layout

- `index.html`, `home.html`, `contact.html`, `info.html` — page entrypoints
- `index.css`, `home.css`, `contact.css`, `info.css` — styles for each page
- `public/` — static assets (images, fonts, etc.)
